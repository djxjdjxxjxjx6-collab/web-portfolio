# Web projects

Five demo websites built from scratch with HTML, CSS and vanilla JavaScript. No frameworks, no build step: each project is a single `index.html` you can open in a browser.

Live: https://djxjdjxxjxjx6-collab.github.io/web-portfolio/

| Project | What works |
|---|---|
| [Sumi Ramen Bar](ramen-restaurant/) | Menu with category and diet filters, pickup order with quantities and totals, table booking with time slots and validation |
| [Ironhouse Strength Club](gym-club/) | Weekly timetable with filters, class details dialog with spots left, membership price calculator |
| [Steppe.js 2026](dev-conference/) | Live countdown, two-day agenda with track filters, personal schedule saved in `localStorage` with clash warnings, ticket quantities with team discount |
| [Aino Lehtinen Photography](photographer/) | Masonry gallery with series filter, lightbox with keyboard and swipe navigation, print configurator with live preview, enquiry form |
| [First Commit](js-course/) | In-browser JavaScript playground, curriculum accordion, 5-question quiz with explanations, pricing toggle |

All pages are responsive, keyboard accessible and respect `prefers-reduced-motion`.

## Run locally

Open any `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

Photos in the photographer demo come from [picsum.photos](https://picsum.photos).
